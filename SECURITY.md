# Security policy

NIXZORA is a portfolio project under active development. If you find a security issue, please do not open a public issue. Use GitHub's **Report a vulnerability** button on the Security tab of this repository instead.

Please include the steps to reproduce and the impact you observed. You can expect an acknowledgement within a few days.

The current threat model lives in [docs/security/threat-model.md](docs/security/threat-model.md).
