# ADR-0004: Toolchain versions and data access

- Status: Accepted
- Date: 2026-10-05

## Decision

| Area                    | Choice                                                                             | Why                                                                                                                              |
| ----------------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Package manager / build | pnpm 10 workspaces + Turborepo 2                                                   | One install, cached builds and tests across apps                                                                                 |
| Language                | TypeScript 5.9, strict                                                             | Every tool in the stack supports it today; TypeScript 7 (native compiler) is adopted once Nest, Jest and Next tooling support it |
| API                     | NestJS 11                                                                          | Mature, CommonJS-friendly, well documented; NestJS 12 is evaluated after Phase 3                                                 |
| ORM                     | Prisma 7 with the `@prisma/adapter-pg` driver adapter                              | Typed client generated into `src/generated/prisma`, no native query engine at runtime                                            |
| Web                     | Next.js 16 (App Router) + React 19                                                 | Server rendering for SEO and fast product pages                                                                                  |
| Validation              | Zod 4 in `@nixzora/validation`                                                     | One schema validates on the server and types the clients                                                                         |
| Tests                   | Jest + Supertest (API), Node test runner (packages); Playwright arrives in Phase 3 |                                                                                                                                  |

## Data conventions

- Primary keys are UUIDv7 (time-ordered, index-friendly), generated by Prisma.
- PostgreSQL tables and columns are `snake_case`; Prisma models stay `camelCase` through `@map`.
- Money is integer minor units (`*_cents`) plus a currency code. Never floats.
- Orders snapshot addresses, titles and prices at purchase time.
- `audit_logs` is append-only, enforced by a database trigger (migration `audit_log_append_only`).
- CI fails if `schema.prisma` and the SQL migrations ever drift apart (`pnpm --filter @nixzora/api prisma:drift`).
- Fonts are self-hosted from npm (`@fontsource/*`) so no visitor data goes to a third-party font CDN.
